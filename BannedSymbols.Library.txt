// Encoder-only policy. Tests and command-line tools may use host services.
// Applied in src/DotJpegli/DotJpegli.csproj in addition to BannedSymbols.txt.

// Callers own paths and destinations; the encoder accepts managed buffers/streams.
T:System.IO.File;Let the caller open files and supply a Stream or pixel buffer.
T:System.IO.Directory;Keep directory access in the host application.
T:System.IO.FileInfo;Let the caller open files and supply a Stream or pixel buffer.
T:System.IO.DirectoryInfo;Keep directory access in the host application.
T:System.IO.DriveInfo;Keep drive discovery in the host application.
T:System.IO.FileStream;Accept a caller-owned Stream instead of opening files.
T:System.IO.FileSystemWatcher;Keep filesystem monitoring in the host application.
T:System.Console;Return results or throw exceptions instead of writing to the host console.
T:System.Diagnostics.Process;Keep process execution in validation tools or host applications.
T:System.Diagnostics.ProcessStartInfo;Keep process execution in validation tools or host applications.
N:System.Net;Keep network access in the host application.
N:Microsoft.Win32;Keep registry and Windows-specific services in the host application.

// JPEG bytes must depend on caller inputs rather than ambient clocks or randomness.
T:System.Random;Encoding must be deterministic for the same inputs and options.
P:System.DateTime.UtcNow;Accept caller-supplied timestamps for metadata.
P:System.DateTimeOffset.Now;Accept caller-supplied timestamps for metadata.
P:System.DateTimeOffset.UtcNow;Accept caller-supplied timestamps for metadata.
P:System.Globalization.CultureInfo.CurrentCulture;Use invariant culture or the culture explicitly required by metadata.
P:System.Globalization.CultureInfo.CurrentUICulture;Keep UI culture in the host application.
